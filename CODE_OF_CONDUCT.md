# PrintChum Code of Conduct

## Our Pledge

We are committed to making participation in the PrintChum project a
harassment-free experience for everyone, regardless of age, disability,
ethnicity, gender identity and expression, level of experience, nationality,
personal appearance, race, religion, or sexual identity and orientation.

## Expected Behavior

Examples of behavior that contribute to a positive environment include:

- Using welcoming and inclusive language
- Respecting differing viewpoints and experiences
- Accepting constructive criticism gracefully
- Focusing on what is best for the project and its users
- Showing empathy toward other contributors

## Unacceptable Behavior

Examples of unacceptable behavior include harassment, discriminatory language,
personal attacks, public or private intimidation, publishing others' private
information, and other conduct that would reasonably be considered
unprofessional in a project community.

## Enforcement

Report unacceptable behavior privately through the maintainer contact listed
in `SECURITY.md`. Project maintainers will review reports and may remove,
edit, or reject contributions that violate this code.

Maintainers will respect the privacy of anyone reporting an incident and will
apply corrective action proportionate to the circumstances.

## Scope

This code applies within project spaces and when an individual is officially
representing the project in public spaces.
